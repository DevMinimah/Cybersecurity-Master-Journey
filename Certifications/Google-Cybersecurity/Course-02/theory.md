# Course 02: Play It Safe: Manage Cybersecurity Risks


## 📅 Date Started: 2026-06-03
## 📅 Date Completed: 2026-06-06

## 🎯 What I Learned:
- CISSP 8 security domains: Overview of the eight domains that structure professional cybersecurity practice
- Threats, risks, and vulnerabilities: Understanding how these concepts impact business operations and security posture
- Security frameworks and controls: Using established frameworks as foundational starting points for developing organizational policies and processes
- CIA triad application: Applying Confidentiality, Integrity, and Availability principles to real-world security scenarios
- NIST frameworks: Leveraging NIST guidelines for structured risk management and security program development
- Security design principles: Core principles that guide secure system architecture and implementation
- Security audits: Understanding how frameworks, controls, and design principles support compliance and audit readiness
- SIEM dashboards: Using Security Information and Event Management tools for monitoring, detection, and incident response
- Playbooks: The development and use of standardized procedures to protect assets and data during security events
- Security analyst workflow: Managing multiple concurrent tasks while maintaining focus on priority security operations

## 💡 Key Takeaways:
- The CISSP domains provide a comprehensive structure for organizing cybersecurity knowledge and practice
- Risk management is proactive—identifying threats and vulnerabilities before they impact business operations
- Frameworks like NIST are not rigid rules but adaptable starting points for building effective security programs
- The CIA triad remains the universal lens for evaluating security decisions across all domains
- Security audits validate that controls are implemented correctly and operating as intended
- SIEM tools centralize visibility, enabling faster detection and response to security events
- Playbooks ensure consistent, repeatable responses to common security scenarios, reducing human error under pressure
- Security analysts must balance technical tasks with communication, documentation, and prioritization skills
- Security design principles like least privilege and defense-in-depth should be applied from the earliest stages of system development
