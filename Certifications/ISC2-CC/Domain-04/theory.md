# Module 04: Network Security (Domain 4)

## 📅 Date Started: 2026-04-25
## 📅 Date Completed: 2026-04-25

## 🎯 What I Learned:
- Networking Fundamentals: OSI model, TCP/IP suite, IPv4/IPv6, ports, and protocols
- Network Threats: DDoS, MITM, malware (virus, worm, Trojan), and side-channel attacks
- Detection & Prevention Tools: IDS/IPS, HIDS/NIDS, firewalls, antivirus, and vulnerability scanning
- Security Infrastructure: Network segmentation (VLAN, DMZ, VPN), defense-in-depth, NAC
- Cloud Security Models: IaaS, PaaS, SaaS, hybrid environments, and SLA considerations

## 💡 Key Takeaways:
- Understanding network architecture is essential for identifying and mitigating threats
- No single tool provides complete protection; layered security is non-negotiable
- Cloud security requires shared responsibility awareness between provider and customer
