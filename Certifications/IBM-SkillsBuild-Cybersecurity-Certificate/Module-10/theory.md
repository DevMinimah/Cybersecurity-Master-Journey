# Module 10: Security Monitoring

## 📅 Date Started: 2026-05-24
## 📅 Date Completed: 2026-05-25 

## 🎯 What I Learned:
- Security monitoring fundamentals: Infrastructure monitoring, network reconnaissance, network security scanning, application monitoring, and user monitoring
- Network reconnaissance: Techniques and tools for gathering information about network infrastructure and identifying potential vulnerabilities
- Endpoint monitoring: Understanding endpoint detection and response (EDR) tools, their benefits, and key features for real-time threat detection
- Endpoint management: Applying principles of endpoint management using EDR tools to monitor, detect, and respond to threats on endpoints
- Security Information and Event Management (SIEM): The SIEM process, benefits of SIEM tools, and centralized log management for security analytics
- Threat investigation: Practical experience performing threat investigations using Splunk Enterprise SIEM platform
- Monitoring tools: Comprehensive coverage of tools for infrastructure, network, application, endpoint, and user activity monitoring

## 💡 Key Takeaways:
- Security monitoring requires a multi-layered approach covering infrastructure, network, endpoints, applications, and users
- EDR tools provide real-time visibility into endpoint activities, enabling rapid detection and response to threats that bypass preventive controls
- SIEM platforms aggregate and correlate security events from multiple sources, providing centralized visibility and enabling faster incident detection
- Network reconnaissance is essential for understanding your attack surface and identifying vulnerabilities before attackers exploit them
- Continuous monitoring is more effective than periodic scanning
-Threats evolve rapidly and require real-time detection capabilities
- Practical tool experience with platforms like Splunk Enterprise is crucial for effective threat investigation and incident response
- The combination of EDR and SIEM provides comprehensive visibility across endpoints and the broader IT environment
