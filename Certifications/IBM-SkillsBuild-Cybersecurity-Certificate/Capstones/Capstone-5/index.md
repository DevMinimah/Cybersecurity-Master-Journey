# Capstone 5: Assemble a SOC Team and Perform Security Monitoring Tasks
## 🛡️ Security Operations & Network Reconnaissance Implementation

>  Simulation-Based Capstone Project  
> *Completed as part of the IBM SkillsBuild Cybersecurity Certificate program. This project demonstrates applied learning in SOC architecture design, security team assembly, and hands-on network reconnaissance using industry-standard tools.*

---

## 🎯 Challenge
Design a tailored Security Operations Center (SOC) model for diverse organizational scenarios, assemble a qualified security team through strategic candidate evaluation, and execute technical network reconnaissance to identify infrastructure vulnerabilities and map attack surfaces.

---

## 🔍 Phase 1: SOC Model Evaluation & Selection
- Action: Analyzed 5 distinct organizational scenarios with varying budgets, scalability needs, and control requirements
- Frameworks Applied: SOC deployment models (In-house, Virtual, SOCaaS, Hybrid)
- Decision Matrix: Balanced Control vs. Cost vs. Scalability vs. Response Time
- Outcome: Recommended optimal SOC architectures aligned with business objectives, risk tolerance, and operational maturity

---

## 👥 Phase 2: SOC Team Assembly & Role Assignment
- Action: Screened 7 candidates against technical certifications, experience, and operational skills
- Advancement Rate: 71% (5/7 candidates advanced to role assignment)
- Roles Filled: Communication Specialist, Security Analysts, Security Engineer, Vulnerability Assessment Specialist and Threat Hunter
- Methodology: Matched skill sets to responsibility tiers, ensuring complementary coverage and 100% role-assignment accuracy
- Outcome: Built a balanced, operationally ready SOC team with clear escalation paths and specialized expertise

---

## 🌐 Phase 3: Network Reconnaissance & Intelligence Gathering
- Action: Executed comprehensive network scanning using Nmap/Zenmap GUI (nmap -T4 -A -v)
- Target Analysis: Identified OS fingerprinting (Linux/Ubuntu), open/closed/filtered ports, and service versions
- Topology Mapping: Visualized network routes and attack paths using Zenmap topology views
- Key Findings: 5 open ports identified, service enumeration completed, actionable security intelligence extracted
- Outcome: Demonstrated proficiency in attack surface analysis, port state interpretation, and infrastructure mapping
