# Module 08: Securing Cloud Infrastructure

## 📅 Date Started: 2026-05-13
## 📅 Date Completed: 2026-05-13 

## 🎯 What I Learned:
- Cloud threats: Mismanaged identities, cloud misconfiguration, denial of service (DoS), insider threats, reduced infrastructure visibility, unauthorized cloud workloads, insecure APIs, and compliance violations
- Shared responsibility model: Understanding security obligations between cloud providers and customers
- Identity and access management (IAM): Controlling access to cloud resources and preventing unauthorized access
- Data loss prevention (DLP): Protecting sensitive data in cloud environments
- Cloud infrastructure security: Securing virtual machines and cloud resources using platforms like Microsoft Azure
- Cloud disaster recovery: Implementing backup and recovery strategies for business continuity
- Cloud application security: Security strategy principles, cloud-native application protection platforms (CNAPP)
- Cloud security tools: Cloud Access Security Broker (CASB) and Cloud Security Posture Management (CSPM)

## 💡 Key Takeaways:
- Cloud security requires a shared responsibility approach—providers secure the infrastructure, customers secure their data and applications
- Misconfiguration and mismanaged identities are among the top cloud security risks
- Proactive, holistic defense is essential given reduced visibility in cloud environments
- CASB, CSPM, and CNAPP tools provide different but complementary layers of cloud security
- Security must be integrated into cloud applications from the design phase, not added as an afterthought
- Disaster recovery planning is critical for maintaining business continuity in the cloud
